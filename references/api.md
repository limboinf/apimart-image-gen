# api.apimart.ai — GPT-Image-2.5 API 参考（离线版）

来源：<https://docs.apimart.ai>（索引：<https://docs.apimart.ai/llms.txt>）。本文件是本地速查副本，
对应页面：图像生成、上传图片、任务查询。

## 0. 模型选择

| 模型 | 特点 | 适用场景 |
|---|---|---|
| `gpt-image-2.5-flare` | 默认款，生成速度快 | 社媒内容、商品图、快速原型、大批量生成 |
| `gpt-image-2.5-sunburst` | 编辑精度优先 | 投放级创意、成品级商品图、多轮精细编辑 |
| `gpt-image-2`（旧） | 仍可用，但不支持 `xhigh` / `max` 档 | 兼容存量 |

两者单价与相同参数下的 token 消耗一致，只权衡速度与精度。与上一代相比，
2.5 新增 `xhigh` / `max` 两档质量，`medium` / `high` 的输出 token 约为旧版同名档位的 1/4。

## 1. 提交任务

`POST /v1/images/generations`，`Authorization: Bearer <key>`

```json
{
  "model": "gpt-image-2.5-flare",
  "prompt": "……",
  "n": 1,
  "size": "16:9",
  "resolution": "2k",
  "quality": "high",
  "output_format": "png",
  "output_compression": 80,
  "background": "transparent",
  "moderation": "low",
  "image_urls": ["https://upload.apimart.ai/f/image/….png"]
}
```

| 字段 | 说明 |
|---|---|
| `model` | 必填：`gpt-image-2.5-flare` / `gpt-image-2.5-sunburst`（旧 `gpt-image-2` 仍可） |
| `prompt` | 必填，中英文均可 |
| `n` | 1~4，纯数字 |
| `size` | 比例（15 种）/ `auto` / 精确像素如 `1600x1200`；图生图建议不传（跟随输入图比例） |
| `resolution` | `1k`（默认）/ `2k` / `4k`；精确像素时被忽略 |
| `quality` | `low` / `medium` / `high` / `xhigh` / `max` / `auto`（默认）；**`xhigh`/`max` 仅 2.5 支持**，传给 `gpt-image-2` 直接 400 |
| `output_format` | `png`（默认，支持透明）/ `jpeg` / `webp`（支持透明） |
| `output_compression` | 0~100，仅 jpeg / webp |
| `background` | `transparent` / `opaque` / `auto`；transparent 仅 png / webp |
| `moderation` | `auto` / `low`（默认；未传时服务端显式按 low） |
| `image_urls` | 图生图/编辑参考图 URL 数组，最多 **16** 张；传入即进入编辑模式 |

响应（注意：不是标准 OpenAI 同步格式，没有 b64_json/url，`data` 是数组）：

```json
{ "code": 200, "data": [ { "status": "submitted", "task_id": "task_01KPQ…" } ] }
```

- `response_format`、`style` 等 OpenAI 标准字段不支持；**base64 data URI 直传已废弃**，
  本地图片必须先走下面的上传接口换 URL。
- `quality: "auto"` 提交时按当前尺寸最高档 `max` 预扣额度，完成后按真实用量结算退差；
  余额敏感时显式指定 `quality`。

## 2. 上传图片（本地参考图必经）

`POST /v1/uploads/images`，multipart/form-data，文件字段名 **`file`**。

```bash
curl -X POST https://api.apimart.ai/v1/uploads/images \
  -H "Authorization: Bearer <token>" -F "file=@/path/to/image.jpg"
```

- 限制：单张 ≤20M；类型 jpg / jpeg / png / webp / gif
- 响应：`{ "url": "https://upload.apimart.ai/f/image/…", "filename": "photo.jpg", "content_type": "image/jpeg", "bytes": 235680, "created_at": 1743436800 }`
- **URL 72 小时有效**，拿到后尽快提交生成任务
- 错误：400 缺字段/类型不支持、413 超 20M、429 限流（带数字 code）、500 失败

## 3. 轮询任务

`GET /v1/tasks/{task_id}`（批量：`POST /v1/tasks/batch`），同一 Bearer Key，建议 2~5s 一次。

```json
{
  "code": 200,
  "data": {
    "id": "task_01KPQ…",
    "status": "completed",
    "progress": 100,
    "actual_time": 52,
    "cost": 0.01325,
    "credits_cost": 0.1325,
    "result": { "images": [ { "url": ["https://upload.apimart.ai/f/image/….png"], "expires_at": 1789000000 } ] },
    "usage": { "input_tokens": 16, "output_tokens": 439, "total_tokens": 455 }
  }
}
```

取图：`data.result.images[].url[]`；`expires_at` 为 Unix 秒（约 24h），过期前需自行下载。
状态：`submitted` → `processing` → `completed` / `failed`；`failed` 看 `data.error.message`，预扣费用自动退回。

## 5. 计费（按 token 用量）

官方单价（每 100 万 token，flare / sunburst 同价）：图片输出 $30、图片输入 $8（缓存命中 $2）、
文本输入 $5（缓存命中 $1.25）。实际扣费受账号分组倍率/折扣影响；`n>1` 按张数线性预扣、
按实结；失败自动退款。

## 6. 限制与错误码

限制：`n` 1~4；参考图 ≤16 张；单边 ≤3840 且为 16 倍数；总像素 655,360~8,294,400；
长短边 ≤3:1；透明背景仅 png/webp；不支持流式部分图。

| HTTP | type | 含义 |
|---|---|---|
| 400 | invalid_request_error | 参数错误：quality 不支持 / 像素非 16 倍数 / transparent+jpeg / 参考图超 16 张 |
| 401 | authentication_error | API Key 无效 |
| 402 | payment_required | 账户余额不足（`auto` 档注意 max 预扣） |
| 413 | invalid_request_error | 上传文件超 20M |
| 429 | rate_limit_error | 请求过于频繁 |
| 500 | server_error | 服务器错误 |
| 503 | service_unavailable | 上游暂时不可用 |
